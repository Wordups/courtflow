# Millers Playbook

Milford Mill girls basketball 26-27 playbook site. Plays organized by game situation and position, with diagrams and video clips.

- `index.html`: the whole site (no build step)
- `img/`: play diagrams
- `video/`: playbook clips (H.264 MP4)

Open `index.html` through any static host (GitHub Pages, Vercel, Netlify). Team use only.
